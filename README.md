# エディトリアル・パートナー by 山本勇磨

英語表記：Editorial Partner by Yuma Yamamoto

縦書きの冒頭から、スワイプで01〜08のカードを切り替える紹介サイトです。

## スマホ・PCで自動更新プレビューを開く

このフォルダで以下を実行します。追加パッケージは不要です。

```sh
python3 dev_server.py --host 0.0.0.0 --port 4174
```

- PC：`http://127.0.0.1:4174/`
- スマホ：PCと同じWi-Fiに接続し、`http://PCのローカルIP:4174/` を開きます。
- 今回のMacのアドレス：`http://192.168.150.134:4174/`（Wi-Fi接続によって変わる場合があります）

CSSを保存すると、表示中のカードを維持してスタイルのみ更新します。
HTML・JavaScript・画像を保存すると、約0.5秒で自動リロードします。
カードのURLハッシュと読み進めた位置は引き継ぎます。
開発用スクリプト・README・隠しファイルは配信しません。
サーバーは実行したターミナルでCtrl+Cを押すと終了できます。
MacのWi-Fiアドレスは `ipconfig getifaddr en0` で確認できます。

従来のPC専用プレビューは以下でも起動できます（自動更新なし）。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## ファイル構成

- `index.html`: 冒頭、本文を直接掲載した8枚のカード、目次メニュー
- `styles.css`: レイアウト、縦書き、カード、Q&Aの開閉表示
- `main.js`: ホールド・ドラッグ・ホイール・キーボード入力、カードの移動、目次
- `dev_server.py`: スマホ対応の自動更新プレビューサーバー
- `.github/workflows/pages.yml`: `main` ブランチ更新時のGitHub Pages公開設定
- `favicon.svg`: ブラウザのアイコン
- `profile-placeholder.svg`: プロフィールの仮画像

## GitHub Pagesで公開する

このフォルダをGitHubリポジトリの `main` ブランチへpushすると、GitHub Actionsが公開用ファイルだけをまとめてPagesへ配置します。開発用の `dev_server.py` とREADMEは公開物に含まれません。

初回のみ、GitHubのリポジトリ画面で **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。以後は `main` へのpushごとに自動更新されます。

GitHub Pagesはインターネット上に公開されるため、確認用URLを知っている人だけに限定する用途には向きません。

## 画面と操作

上向きスワイプで次、下向きで前のカードへ移動します。
カードを紙のメモのように表示し、約160ms押し続けると持ち上がります。押したまま上下左右へ動かせます。
左右の移動ではカードを切り替えず、上下の閾値を超えたときだけ切り替えます。
長い本文は素早い上下スワイプで読み進め、ホールドしてから動かすとカードそのものを移動します。
画面の高さに応じた70〜110pxの閾値を超えると、190msの `ease-in-out` で次のカードへ切り替わります。
閾値に達する前に離すと140msで元の位置へ戻ります。先頭・末尾では抵抗を強くして戻します。
メニューからの移動は240ms。フェードや拡大縮小は使用しません。
PCのホイール入力は動かない画面側で受け、静止したカーソルのまま繰り返し操作できます。
慣性の減衰と新しい入力を区別し、切り替え中の新しい操作は次の1枚分だけ予約します。

本文は各カードに直接表示します。長いカードはそのまま下へ読み進められ、末尾まで読んだ後の新しい操作で次のカードに進みます。
Q&Aのみ、質問を押すと回答を開くアコーディオンです。
ハンバーガーメニューから各カードへ直接移動できます。
上下矢印・PageUp／PageDown・Spaceでも操作でき、Home／Endで最初／最後へ移動します。
端末の「動きを減らす」設定では即時に切り替えます。
